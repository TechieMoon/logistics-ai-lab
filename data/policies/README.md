# 합성 정책 코퍼스 v1.0

`policies.jsonl`의 16개 짧은 정책은 이 포트폴리오를 위해 직접 작성한 **가상 규칙**이다. CJ올리브네트웍스·CJ대한통운의 실제 정책이나 내부 데이터가 아니다. 실제 운영·안전·법률 의사결정에 적용할 수 없다. 각 행 자체를 하나의 검색 청크로 사용하며, 문서 ID와 버전을 응답에 보존한다. 작고 독립적인 정책이므로 임의 문자 수로 분할하지 않는다.

시간, 온도, 확률 기준 등 모든 수치는 교육용 설정이다. 실제 개인정보, 기업 문서, 외부 서비스에 전송하는 데이터는 없다. 정책 내용과 QA는 같은 작성자가 설계한 소형 합성 실험이므로 검색 점수를 실제 현장 성능으로 해석하면 안 된다.
