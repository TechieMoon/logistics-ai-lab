# 동결된 소형 합성 QA v1.0

- 개발 세트: `dev.jsonl` 12문항. 답변 가능 6개, 불가 6개. 거절 임계값은 이 파일만 사용한다.
- 평가 세트: `eval.jsonl` 16문항. 답변 가능 10개(복수 근거 2개 포함), 불가 6개. 검색·거절·생성 결과를 보고하는 용도이다.
- 코퍼스·QA는 최초 실행 전에 작성했다. 평가 결과를 좋게 만들려고 문항이나 정답을 변경하지 않는다. 버그 수정과 데이터 개정은 버전 및 변경 이유를 남겨야 한다.
- 두 파일의 질문 ID와 질문 문자열은 겹치지 않는다. 문서 ID는 겹칠 수 있다. 이는 동일 정책 코퍼스를 검색하는 평가이며, 새로운 정책에 대한 일반화 평가가 아니다.
- `relevant_doc_ids`는 검색 정답, `expected_facts`는 사람이 생성 답변을 검토할 때의 참고 항목이다. 문자열 포함 여부를 사실성·정답률로 포장하지 않는다.
- 검색 recall@k는 정답 문서 중 top-k에 들어온 비율이다. MRR@k는 첫 정답 문서 순위의 역수이다. 답변 불가 문항은 검색 지표의 분모에서 제외하고 거절 지표에서 별도 평가한다.

숫자가 작고 코퍼스 작성자가 정답도 작성했다. 임계값은 확률 보정이 아니며, 검색된 문서가 있다는 사실이 질문에 답할 수 있음을 보장하지 않는다. 특히 정책과 어휘가 겹치지만 요청한 사실은 없는 질문을 별도로 포함했다. 실무 적용 전 독립 평가자, 더 큰 미공개 테스트셋, 실제 정책 권한·버전 관리가 필요하다.
